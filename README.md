# Dominó Club

Prototipo móvil de dominó con monedas exclusivamente virtuales.

## Publicar en GitHub Pages
1. Crea un repositorio llamado `dominoclub`.
2. Sube todos los archivos de esta carpeta.
3. En GitHub abre Settings → Pages.
4. En Source selecciona GitHub Actions.
5. El sitio quedará disponible con la URL de Pages de tu repositorio.
